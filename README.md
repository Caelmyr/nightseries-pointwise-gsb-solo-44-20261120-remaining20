# NightSeries 时序曝光工作台

NightSeries 将同一星场的单色曝光整理成可复查的测光观测。原图、原生探测器坐标、参考帧坐标和曝光中点分开保留。工作台面向本机小批次使用。

## 打开工作台

运行 `docker compose up -d --build`，在浏览器打开 [127.0.0.1:18947](http://127.0.0.1:18947)。设置 `NIGHTSERIES_PORT` 可以改用其他本机端口。通过 `docker compose stop` 停止服务。数据放在本项目的 Compose 命名卷中。暴露给本机的健康地址为 `/api/health`。

原生运行支持 Python 3.11。先在自己的虚拟环境执行 `python -m pip install -r requirements.txt`，然后运行 `./start.sh`。默认数据目录是 `.nightseries`。自定义数据路径、监听主机和端口分别使用 `NIGHTSERIES_DATA`、`HOST` 和 `PORT`。本机工作台没有账户管理。

## 观测一晚

1. 点击「打开疏散星场」建立合成观测，或新建空白观测并导入科学曝光。疏散星场含 14 张 V 波段科学曝光、9 张校准参考及固定孔径。导星漂移样例含 16 张 R 波段曝光，可用于自动对准演练。两组都由代码生成。
2. 在「采集与校准」核对波段、开始时间和曝光秒数。可挂起选定帧，选择主偏置、曝光匹配暗场、同滤镜平场以及需要回避的探测器坏区。
3. 在「影像阅览」切换原始、校准、对准图层，点击像素查看数值。图面支持标孔径、框选坏区、画像素剖面、查看分布或星点。拉伸只用于显示。
4. 在「对准与差分」核对参考帧。既可手工输入每张图的亚像素位移，也可计算影像比较候选。当前可用的两张对准图可闪烁或用公共有效像素做带符号差分。
5. 在「孔径光度」选择一颗目标星和一颗比较星，可再选择一颗检查星。输出逐帧孔径净光度、差分星等、缺测原因和日期曲线。疏散星场的目标星在中段变暗，检查星差分维持较稳。结果可下载 CSV 或保存到归档。已保存结果保留计算当时的数据。
6. 在「曝光质检」检查逐帧星点宽度、拖尾、背景及覆盖。在「叠加」合并同滤镜科学曝光，分别下载定量 FITS 和覆盖计数 FITS。
7. 下载观测包可把原图、校准、参考位移、探测器掩膜、孔径、图幅设置、本地星表和结果归档搬到另一安装。

「核验工具」提供下列独立检查。

| 检查 | 输入和可见输出 |
| --- | --- |
| 曝光时序 | 复核快门开始、结束、并集覆盖、长间隔和重叠。可按文件名预览并应用独立 UTC 日志。 |
| 天区坐标 | 用参考曝光 TAN 头或手工定标星计算星图方向、尺寸与像素坐标，导入后可查看本地星表是否入场。无 TAN 头时可用粗略中心、每像素角度和相机朝向自动配对本地星表，先核对参考图上的对应连线、残差与状态（唯一、角隅集中、多解），确认后才写入天区坐标。 |
| 图幅一致性 | 从重复曝光的图像头校核位移后控制点的天球残差。分别保留缺头、坐标系冲突和超差。 |
| 导星光心 | 在受限区域内测量所选星点的原生漂移、对准后残差和有效性。 |
| 坏点监测 | 用多张暗场、偏置或平场核实重复异常，可选择通过检查的坏区放进探测器掩膜。 |
| 增益复核 | 对匹配平场与偏置成对取样，报告读取噪声及预计转换增益。合成校准图主要用于流程演练。 |
| 天空背景图 | 排除星点并以有效格计算背景趋势，显示拟合场、残差和支持不足的区域。 |
| 孔径生长 | 在固定背景环和同一组曝光中改变圆孔半径，检查累计光度与信噪比。 |
| 配对强度 | 用对准后同滤镜两帧的原像素率检查平均强度比例、常量偏差和空间残差。 |
| 共同覆盖 | 选择支持标准和最少曝光数，检查参考画幅内真实像素的覆盖；金框给出最大合格内矩形。 |
| 区域光度 | 在参考坐标选取扩展目标与独立天空矩形，量测每像素净亮度和净率，不足的帧记录为缺测。 |
| 曝光预览册 | 将原图或对准图配成一张接触册，可在同滤镜中使用统一显示范围。 |
| 孔径取证框 | 按参考孔径中心取各帧原生探测器小图，导出 FITS、PNG 与像素原点清单。 |

## 输入和数值边界

- 读二维主 FITS 图像及灰度 PNG、单页 TIFF。FITS 支持 BITPIX 8、16、32、−32、−64，应用 BSCALE 和 BZERO，剔除 BLANK、非有限值及绝对值超过 10¹⁵ 的样本。程序直接保存上传字节，下载原图不重新编码。FITS 图像头约定参考 [NASA FITS 标准](https://fits.gsfc.nasa.gov/fits_standard.html)。
- FITS 使用 UTC 或 UT 的 DATE-OBS、EXPTIME 和 FILTER。如时间系统不符，在导入时补填写换算后的 UTC。灰度图需要手工填写曝光元数据。差分时间是 UTC 快门中点，未做重心时标转换。
- 每组同画幅，单张至少 16 × 16，最多 1,048,576 像素和 10 MiB。一组最多 48 张、96 MiB 原图和 20 个孔径。一个交换 ZIP 最多 120 MiB。常规重计算分别受 2400 万输入像素及两个计算槽限制。中位叠加的输入预算为 1200 万像素。
- 跨帧对准为平移模型。人工天球定标用于窄视场，FITS 天球坐标限标准赤经／赤纬无畸变 TAN 的度值头。头与内容的配对由工作台使用者核实。天球坐标约定参考 [NASA WCS 文档](https://fits.gsfc.nasa.gov/wcs/)。
- 孔径测光以参考坐标定圆心，在独立原生曝光采样。探测器坏区、边缘覆盖与饱和均影响可用性。差分光度取同滤镜的同时有效样本。背景趋势、增益、质检和导星计算适用于本机观测对照。
